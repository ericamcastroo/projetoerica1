# Sistema de Gerenciamento de EPIs - Controle de Colaboradores

Projeto desenvolvido em Python/Django para gerenciamento de Equipamentos de Proteção Individual (EPIs) voltado para indústrias do setor têxtil.

## Funcionalidades Implementadas

- **Cadastro de Colaboradores:** Inserção de novos colaboradores com feedback dinâmico via Bootstrap.
- **Listagem e Pesquisa:** Tabela responsiva com barra de busca por nome.
- **Edição:** Atualização dos dados cadastrais dos colaboradores.
- **Exclusão Segura:** Remoção de colaboradores antecedida por confirmação via Modal Bootstrap.
- **Persistência de Dados:** Integração com banco de dados SQLite.
